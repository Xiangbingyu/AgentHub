# 文件命名规范

## 文件命名规则

```bash
# 普通文件：小写+中划线
this-is-an-example.ts

# React组件/页面：大驼峰
ThisIsAnExample.tsx

# 组件目录
component-name/
├── index.tsx        # 组件实现
└── index.scss       # 样式文件

# 页面目录
PageName/
├── index.ts         # 页面入口
├── PageName.tsx     # 页面组件
├── http.ts          # 页面API
├── interface.ts     # 类型定义
└── drawer/          # 抽屉组件
```
