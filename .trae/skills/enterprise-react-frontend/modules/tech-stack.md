# 技术栈

| 类别 | 技术 |
|------|------|
| 框架 | React 18.x |
| UI库 | Ant Design 5.x |
| 状态管理 | Zustand |
| 路由 | React Router v6 |
| 构建 | Vite 5.x |
| 语言 | TypeScript 5.x |
| 懒加载 | React.lazy + Suspense |
| 包管理器 | pnpm / npm |
| Node版本 | 18.x+ / 20.x |

## 主要特性

- React 18: 并发渲染、Suspense、useTransition
- Ant Design 5: CSS-in-JS、Design Token、组件重写
- Zustand: 轻量级状态管理、简洁API
- Vite: 快速HMR、按需构建
